# Structural optimization investigation checklist

This checklist records the authorized investigation and conditional planning,
not production implementation. If no candidate earns selection, a decision to
stop satisfies the user objective without inventing a runtime migration plan.

## 1. Ground the candidate inventory

- [x] 1.1 Preserve the existing checkout and freeze exact source/build identity.
- [x] 1.2 Map streaming, actors/render presentation and registry mechanisms from actual source.
- [x] 1.3 Capture fresh High/Low driving and High parked sampled CPU attribution with supervised teardown.
- [x] 1.4 Run the first real council and record its synthesized experiment order and protected contracts.

## 2. Run bounded discriminators

- [x] 2.1 Capture actual pedestrian requests, preserving the failed settling-only attempt and the corrected full-route trace separately.
- [x] 2.2 Prove exercised exact-support equivalence and measure cold/warm net costs; retain the no-go result.
- [x] 2.3 Prove exercised registry publication/query order and measure complete publication/maintenance plus lifecycle costs; retain the no-go result.
- [x] 2.4 Declare rendering mechanisms and nomination filter before captures, then create a disposable build without editing application sources.
- [x] 2.5 Capture Low/High matrix-only and spatial shopkeeper comparisons for all three cameras at Noon/Midnight, retaining raw data and unfavorable results.
- [x] 2.6 Regenerate rendering summaries, retain scope limits and independently inspect every recorded browser/worker process identity.

## 3. Challenge selection and remaining scope

- [x] 3.1 Obtain a cited adversarial selection audit and complete a finite retrospective residual-cost triage.
- [x] 3.2 Complete the second real council and resolve whether to select, run a justified further discriminator, or stop without a rewrite.
- [x] 3.3 If a candidate is selected, produce its exhaustive proposal/specification/design/implementation/verification plan and refine through at most three full deliberations until review no longer improves it; otherwise record why conditional planning is not activated.

## 4. Close the investigation

- [x] 4.1 Independently fact-check the final selection or stopping record, resolve material findings and verify convergence.
- [x] 4.2 Check documentation links/status and baseline preservation, stop owned keep-awake activity and verify exact cleanup.
- [x] 4.3 Audit the original goal requirements and record the final evidence-backed outcome without claiming production or device acceptance.
