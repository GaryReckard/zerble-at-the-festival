## Context
- **Task**: Add textured dirt roads and selectively wider paved approaches that follow the festival layout, while preserving existing road routes, deterministic generation, terrain conformity and bounded rendering.
- **Personas Consulted**: Architect, Adversary, Profiler + Mediator
- **Date**: 2026-10-28
- **Mode**: Synthesis. The three completed Round 1 positions were read in full; no Round 2 was run.
- **Verdict**: Proceed with mitigations. The authorized implementation can proceed using the decisions below without another policy approval.
- **Evidence boundary**: This is a source-backed planning review, including the Adversary's recorded production-worldgen shoreline probe. It is not browser acceptance, device performance evidence or an assertion that the planned tests already pass.

## Synthesized Plan

TL/DR: Keep existing roads exactly where they are, pave major-hub edges only when their full nine-metre footprint is dry, and leave other edges as seven-metre dirt. Keep the existing nine-metre planner envelope by spending the dirt shoulder on the wider asphalt surface, preserve planner execution exactly, and audit actual built footprints separately before texturing existing meshes.

## Final Recommendation
Proceed with mitigations and update the draft according to Group 1 before implementing. The shoreline conflict has a concrete resolution: preserve all routes and use a deterministic whole-edge dirt fallback wherever the full nine-metre candidate footprint is unsafe, while treating inherited dirt defects separately. The uniform planner envelope preserves candidate and RNG execution, while the remaining gates protect actual built footprints, renderer ownership and measured cost without requiring a new architecture or another human policy decision.

## Decision Amendment: Uniform planner envelope

The orchestrator proposed preserving the already reserved envelope instead of introducing planner repairs. **Accepted for planner compatibility**, because the existing full-shape clearance is `7 / 2 + 1 = 4.5` metres (`src/worldgen/roads.js:359`) and the food-court gate reserves `courtRing + 4.5` metres (`src/worldgen/festival.js:1026`). Dirt at width seven with shoulder one and asphalt at width nine with shoulder zero therefore reserve the same nine-metre corridor. Preserve the existing candidate lateral offsets as well (`src/worldgen/festival.js:1044`); changing them merely because visible width changes would undermine this compatibility benefit. A uniform reserved distance also makes nearest-centerline comparison sufficient for that reservation, so the mixed-width counterexample does not require replacing an already uniform planner predicate.

This decision supersedes any suggestion that a broad planner repair phase is a prerequisite. The baseline festival plan, its random draw execution and its published descriptors must remain unchanged. The full-footprint shoreline test and deterministic whole-edge dirt fallback still apply, because road placement only tested sampled centerlines (`src/worldgen/roads.js:123,196`) and no existing dry-land shoulder reservation proves the asphalt footprint is dry. The recorded seed and endpoint pair remain mandatory fixtures ([Adversary, shoreline finding](council-adversary.md#vulnerabilities-found)).

**The limit is physical footprints in builder checks.** `src/chunks.js:1657` tests a booth center against 4.5 metres, and `src/worldgen/lint.js:464-468` explicitly describes its additional metre as the booth radius/grazing margin. It cannot simultaneously be promised as an empty shoulder and spent on asphalt. This is not evidence that the pure planner needs repair, nor a verified new in-game collision coordinate; it establishes that uniform planner reservation alone is insufficient proof for every built object. Audit those consumers and add full occupied-footprint fixtures, retaining planner output and using narrowly scoped builder corrections only where required. Woodland's `3.5 + 2` reservation (`src/woodlandCamping.js:41`) and tree scatter's matching margin (`src/chunks.js:1100`) leave one metre beyond the nine-metre ribbon when held unchanged; consumers with less margin, such as `src/chunks.js:2405`, require their own footprint assessment. There is no blanket permission to shrink object footprints or change old RNG execution.

Acceptance is actionable: prove identical original route/query/POI fixtures and planner draw execution; prove the dry-major asphalt case and recorded shoreline dirt fallback; check every audited physical footprint against all nearby visible ribbons; and distinguish uniform reserved-envelope lint from actual visible-surface collision lint. This keeps the simple compatibility-preserving design without accepting an unsupported guarantee about all center-only builders.
